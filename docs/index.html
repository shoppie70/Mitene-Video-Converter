FAQ

気になること。

ダウンロード前に知っておきたい点をまとめました。

本当に設定はいりませんか？

基本的にいりません。動画を入れれば、長さ・解像度・フレームレート・形式を自動で整えます。

みてねへ直接アップロードできますか？

直接アップロードはしません。変換後の動画を写真アプリへ追加し、iPhoneのみてねアプリから選びます。

初回起動時に警告が出ますか？

現在の配布版は未公証のため、確認が表示される場合があります。アプリを右クリックして「開く」を選んでください。

みてね公式のアプリですか？

いいえ。家族アルバム「みてね」を利用しやすくするための非公式ツールです。
